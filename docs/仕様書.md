# 仕様書（BUN & CO.）

クラフトバーガー店サイトの React 再構成版の仕様と、それを実現しているファイルの対応。コードの読み方は [`コード説明.md`](コード説明.md)、部品の分け方の理由は [`設計の意図.md`](設計の意図.md)。

## 1. 概要

| 項目 | 内容 |
|---|---|
| 位置づけ | 実案件（2025年5〜10月／クラフトバーガー店）の WordPress 専用テーマを組み直した版。クライアントの許可を得て掲載。閉店済みのため、店名・商品・連絡先は架空のものに差し替え |
| 担当範囲 | テーマ設計・HTML/CSS/JavaScript・Instagram表示連携・BGM切替・外部導線（Uber Eats／LINE）・アイコン制作（音楽ボタン・配達アイコン）・ロゴ制作への参加。写真は元サイトと同じフリー素材を使用（グッズのみ Unsplash・写真の加工は担当外） |
| 技術 | Next.js 16（App Router）・React 19・TypeScript・SCSS Modules（Sass）。外部の UI ライブラリ・jQuery なし |
| 公開 | Vercel（https://bun-and-co.vercel.app）。`main` に push すると本番に反映 |
| 検索 | 出さない（全ページ noindex〈404 は index:false のみ〉・応答ヘッダーで全ページ noindex, nofollow） |
| 実装 | Claude Code を併用。設計（コンポーネント分割・データ分離の方針）と全コードの確認・判断は本人 |

## 2. ページ構成

| ページ | URL | 中身 | ファイル |
|---|---|---|---|
| トップ | `/` | メインビジュアル → ABOUT → 写真の帯 → MENU（4 品） → NEWS → ACCESS。BGM ボタン | `src/app/page.tsx`、`components/home/*` |
| MENU | `/menu` | カテゴリへのページ内リンク、BURGERS・SIDES（写真つきカード）、DRINKS・FLOATS・ALCOHOL（名前と価格の表） | `src/app/menu/page.tsx`、`components/menu/*` |
| GOODS | `/goods` | 紹介文・LINEUP（6 品のカード）・注意書き | `src/app/goods/page.tsx`、`components/goods/GoodsList.tsx` |
| CONTACT | `/contact` | 電話の窓口、お問い合わせフォーム | `src/app/contact/page.tsx`、`components/contact/ContactForm.tsx` |
| PRIVACY POLICY | `/privacy-policy` | 条文 | `src/app/privacy-policy/page.tsx`、`data/privacy.json` |
| 404 | 存在しない URL | 案内文・トップへのボタン・主なページへのリンク | `src/app/not-found.tsx` |

全ページ共通：ヘッダー（ロゴ・ナビ・外部リンク・SP はハンバーガー）、フッター（ロゴ・店舗情報・フッターメニュー・SNS）、PAGE TOP ボタン、ダミーリンクの案内 → `src/app/layout.tsx`、`components/layout/*`

## 3. 機能

| 機能 | 仕様 | ファイル |
|---|---|---|
| ヘッダーの切り替え | 200px スクロールで、ロゴのマークが店名の文字に替わり、ヘッダーが半透明になる | `Header.tsx`・`Logo.tsx` |
| ドロワー（SP） | ハンバーガーで開閉。開いている間は背景のスクロールを止める。リンクを押すと閉じる | `Header.tsx`・`DrawerNav.tsx` |
| 現在地の表示 | 今いるページのナビに `aria-current="page"` | `Header.tsx` |
| 商品の詳細 | カードを押すと `<dialog>` のモーダルで写真・名前・価格・説明・選べるもの。Esc・背景クリック・× で閉じる。トップ・MENU・GOODS で同じ部品 | `MenuCard.tsx`・`ProductModal.tsx` |
| カテゴリの表示切り替え | `menu.json` の `layout` が `card` なら写真つきカード、`list` なら名前と価格の表 | `MenuSection.tsx`・`PriceTable.tsx` |
| BGM | トップの左下に固定のボタン。押すと `<audio loop>` を再生／停止。再生中はボタンが鼓動のように拡大・縮小 | `BgmToggle.tsx` |
| メインビジュアル | 6 枚の写真が順にフェード（CSS アニメーション） | `Hero.tsx` |
| 写真の帯 | 写真が横に流れ続ける（90 秒で 1 周・継ぎ目なし） | `PhotoLoop.tsx`・`data/gallery.json` |
| スクロールで出現 | 画面に入ったら下から表示（1 回だけ）。JS が動かない環境では最初から表示 | `FadeIn.tsx`・`layout.tsx` |
| 見出しの下線 | スクロール量に合わせてのびる（CSS の scroll-driven animation。未対応のブラウザは表示時に 1 回） | `SectionTitle.module.scss` |
| PAGE TOP | 150px スクロールで下からせり上がる。押すとページの先頭へ | `PageTop.tsx` |
| お問い合わせ | 入力の確認（必須・メール形式・電話の形式・同意）。エラーは欄の下に出し、最初のエラー欄へフォーカス。送信先は持たず、送信後に「作品のため実際には送信されない」と表示 | `ContactForm.tsx` |
| 外部リンク | Instagram・LINE・Uber Eats。URL が `#` の間は、押すと「架空の店のため、リンク先はありません」を 2.5 秒表示。本物の URL を入れると別タブで開く | `ExternalLink.tsx`・`DummyNotice.tsx` |
| NEWS | 投稿 6 件のグリッド。キャプションは hover／フォーカスで表示、タッチ端末では常に表示。静的なデータ（元の WordPress 版は Instagram Feed プラグインのショートコード。Graph API 版は試作のみ） | `News.tsx`・`data/news.json` |
| ACCESS | 店舗情報・案内図（画像）・外部導線のボタン（Uber Eats で注文する／LINE で友だち追加） | `Access.tsx`・`StoreInfo.tsx` |

## 4. データ（`src/data/`）

| ファイル | 中身 | 使う場所 |
|---|---|---|
| `store.json` | 店名・紹介文・住所・電話・営業時間・定休日・SNS の URL・コピーライト・説明文 | ロゴ・ABOUT・ACCESS・フッター・各ページの metadata |
| `nav.json` | グローバル／外部／フッター／SNS のメニュー | ヘッダー・ドロワー・フッター・404 |
| `menu.json` | カテゴリ（BURGERS 6・SIDES 5・DRINKS 6・FLOATS 3・ALCOHOL 4）と商品 | MENU・トップの MENU |
| `goods.json` | 紹介文・注意書き・グッズ 6 品 | GOODS |
| `news.json` | 投稿 6 件 | トップの NEWS |
| `hero.json` | メインビジュアルの写真 6 枚 | トップ |
| `gallery.json` | 写真の帯 | トップ |
| `privacy.json` | プライバシーポリシーの条文 | PRIVACY POLICY |

データの形（型）は `src/types/data.ts`。画像は `public/images/<用途>/`、音源は `public/audio/bgm.mp3`。

## 5. 画面幅（ブレークポイント）

| 幅 | 呼び方 | 指定のしかた |
|---|---|---|
| 〜767px | SP | 基本の書き方（SP ファースト）。`@include sp` で SP だけの指定 |
| 768px〜 | タブレット以上 | `@include tablet` |
| 1024px〜 | PC 以上 | `@include pc` |

値は `src/styles/_variables.scss`（`$bp-tablet`・`$bp-pc`）、mixin は `_mixins.scss`。確認は 375px と 1440px で撮影（`scripts/screenshot.mjs`）。

## 6. 公開・検索・安全の設定

| 項目 | 設定 | ファイル |
|---|---|---|
| 検索に出さない | 全ページ noindex（`layout.tsx` の `robots: { index: false, follow: false }`。404 の `not-found.tsx` は `{ index: false }` のみ）。応答ヘッダー `X-Robots-Tag: noindex, nofollow` で全ページに nofollow も付く | `layout.tsx`・`not-found.tsx`・`next.config.ts` |
| タイトル | `ページ名｜店名`（トップは `店名｜クラフトバーガー専門店`） | `layout.tsx`・各 `page.tsx` |
| OGP | 画像 `/images/ogp.png`（1200×630）。絶対 URL は環境変数 `NEXT_PUBLIC_SITE_URL` | `layout.tsx` |
| セキュリティ用の応答ヘッダー | `X-Content-Type-Options: nosniff`・`X-Frame-Options: DENY`・`Referrer-Policy: strict-origin-when-cross-origin`・`Permissions-Policy`（カメラ・マイク・位置情報を止める） | `next.config.ts` |
| 外部リンク | 本物の URL のときは `target="_blank"` と `rel="noopener noreferrer"` | `ExternalLink.tsx` |
| フォーム | 送信しない作り（入力は外に出ない） | `ContactForm.tsx` |

## 7. 使いやすさへの配慮（アクセシビリティ）

| 内容 | ファイル |
|---|---|
| ハンバーガーに `aria-expanded`・`aria-controls`・開閉で変わる `aria-label` | `Header.tsx` |
| モーダルは `<dialog>`（Esc で閉じる・フォーカスはブラウザが移す）、`aria-labelledby` で題名を結ぶ | `ProductModal.tsx` |
| BGM ボタンに `aria-pressed` | `BgmToggle.tsx` |
| フォームのエラーを `aria-invalid`・`aria-describedby` で伝え、最初のエラー欄へフォーカス | `ContactForm.tsx` |
| ダミーリンクの案内を `role="status"`・`aria-live="polite"` で読み上げ | `DummyNotice.tsx` |
| 動きを減らす設定では、写真のフェード・流れる帯・鼓動・出現などの動きを止める | 各 `*.module.scss` |
| ヘッダーの配達アイコンのホバーの動きは、`:focus-visible`（キーボードで選んだとき）でも同じに | `Header.module.scss` |
